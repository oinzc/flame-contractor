# Flame Contractor 独立 Android 版 v2A 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在独立 Android 客户端落地跨端全双工 JSON 备份/迁移（含 Python 后端备份接口兼容修复）、后台周期只读自动扫描与官方火花告急双通道提醒、以及第 5 主导航 Tab「记录」（30 日历史统计、尝试时间线与脱敏 CSV 导出）。

**Architecture:** 保持 Android 单机离线自治架构——Room 升级至 `version = 3`（`MIGRATION_2_3`），纯 Kotlin `ExecJson` 与纯 JVM 领域模块（`BackupCodec`、`SparkDeteriorationDetector`、`AutoScanPlanner`、`HistoryStatsCalculator`、`HistoryCsvExporter`）零 Robolectric 可测；后台调度复刻后端避开发送窗与冷却策略，由 `ScheduleCoordinator` 独立闹钟槽位 + `SafetyNetWorker` 驱动 `ExecutionForegroundService`；Python 后端在 `BackupRead` 精准放行 `androidExtensions` 并在 `backup.py` 修复子表归属校验与自然键合并。

**Tech Stack:** Kotlin 2.0.21, Gradle 8.11.1, AGP 8.7.3, JDK 17, Android SDK 35 (`minSdk = 26`, `targetSdk = 35`), Jetpack Compose Material 3, Room 2.6.1 (KSP), WorkManager 2.10.0, JUnit4 / Kotlin Coroutines Test; Python 3.12, FastAPI, SQLModel, pytest.

## Review Focus

- **后端严格 Schema 与 naive ISO 时间戳**：`BackupRead` 接受并忽略 `androidExtensions` 同时保持其余接口 `extra="forbid"`；Android 正确解析带 `Z`、数字时区偏移（`+08:00`）与无偏移 naive UTC ISO-8601 时间戳，以及 camelCase / snake_case 双顶层键（Task 1 与 Task 3 测试覆盖）。
- **跨端迁移同日防重复发送**：桌面端同日 `message_slot_id = "<tpl>:v1"` 及切换模板产生的多条记录导入 Android 后，按安全优先级 `UNKNOWN_REQUIRES_REVIEW > SUCCEEDED > FAILED_TERMINAL > FAILED_RETRYABLE > CANCELLED > SCHEDULED > ...` 将最高优先级条落入 `"daily"` 锁定 `SendGuard.canDispatchDaily`，且不覆盖已有本地 `UNKNOWN_REQUIRES_REVIEW`（Task 3 测试覆盖）。
- **超大/损坏备份与跨午夜窗口防御**：超过 `20 MB`（`20 * 1024 * 1024` bytes）或非法/截断 JSON 在开启 Room 事务前直接拒绝、零写入；桌面端跨午夜窗口（如 `23:00–01:00`）导入时不破坏 Android 同日窗口约束，保留本地有效窗口并写入 `warnings`（Task 3 测试覆盖）。
- **自动扫描防刷屏与发送窗避让**：断火落库 `"无火花"` 后次日再扫 `"无火花"` 不重复告警；计划扫描时间落入 `[sendWindowStart - 15m, sendWindowEnd]` 或启用好友固定时刻 `[fixed - 15m, min(fixed + 60m, 23:59)]` 时顺延至合并阻塞区间末尾（越过 `23:55` 顺延至次日 `00:05`）；发送或鉴权复判与自动扫描同轮到期时发送严格优先（Task 4 与 Task 5 测试覆盖）。
- **脱敏诊断标识符防误伤与隐私防线**：`SanitizedDiagnosticsBuilder` 新增输出字段名长度严格 `< 24`（`autoScanEnabled`、`autoScanIntervalHours`、`latestAutoScanStatus`、`latestAutoScanAtIso`）以避免触发 `LONG_OPAQUE_TOKEN_REGEX`，且绝不输出 `scan_runs.alert_summary` 中的好友昵称（Task 8 测试覆盖）。
